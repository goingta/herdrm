## 页面结构

1. **顶部单行**：左侧保留 `sidebar.left`；其后为当前 pane 的 Agent 图标（有 Agent 时）与真实会话名称；右侧为气泡/终端分段切换，再为省略号菜单。去掉现有固定 herdrm 标题和独立 Space/开发机标题块。普通终端标题采用现有终端名称；没有目标时才显示品牌或实际空状态。长标题截断，完整名称可通过辅助功能与更多菜单查看。
2. **侧栏**：从左侧覆盖主区，默认收起；包括当前开发机选择、连接状态、该机 Space 列表、当前选择标记及开发机管理入口。选择 Space 后收起。继续使用真实身份和状态，不能按名称猜测归属。侧栏视觉、行间距和层级参考 web-ui。
3. **Tab 行**：真实名称和远端顺序、横向滚动、当前项可见、琥珀色下划线；分屏切换菜单放在当前 Tab 的下拉入口中，取消现有额外分屏标题行。切换不会混入其他 Space，快照不抢走仍有效的本地选择。
4. **聊天模式**：提供真实用户/Agent 对话、Markdown 段落、列表、代码块、复制、工具调用及思考内容的折叠展示；底部是参考样式的圆角输入卡片、附件入口、实际模型/推理信息、发送按钮。支持历史分页、新内容更新和回到底部。服务返回普通 scrollback 时明确显示其降级性质，不能伪造结构化消息。
5. **终端模式**：保留现有 SSH 终端渲染与输入能力，调整布局、终端配色、输入框和按键条以符合参考界面。终端字符内容不翻译、不转换成聊天记录。
6. **更多菜单**：提供当前名称和开发机/Space 上下文、刷新当前模式、连接/聊天服务状态及可用的现有管理入口；动作必须有真实实现。不得显示没有功能的菜单项或假通知点。
7. **底部栏**：沿用当前三个入口及行为。离开主工作区再返回不丢选择、两种模式的草稿、终端画面和聊天滚动位置。

先前“只操作已有 Agent”仍有效：本轮不创建/删除 Agent、Tab 或分屏；因此不显示参考图中用于新建 Tab 的 `+`。聊天输入卡片的 `+` 用于附件，是不同功能。模型/推理信息在参考源码中是只读显示，本轮也不将它伪装成模型设置按钮。

## 聊天服务配置与认证

每个原生开发机可选绑定一个服务地址与 web machine。默认不为所有开发机自动套用用户的服务地址；首次可从当前地址建立配置：
`https://vscode-tanglei-7861.web.azshentong.com:5666/`。

- 在公开配置界面保存 HTTP(S) 地址和选择服务中的 machine；针对本用户部署使用 HTTPS。登录凭据由用户在 App 内填写服务 token 或完成该服务支持的配对，存入 Keychain，不写入配置 JSON、URL、日志或网页脚本。
- SSH 公钥与 web-ui 凭据是两个独立认证。不要读取或迁移 Safari 登录状态，不改用户远端认证或服务配置。
- 获取已认证 machine 列表，让用户明确绑定。原生开发机 UUID 不等于 web machine ID；`local` 只表示服务的本地 herdr。读取前核对所绑定 machine 的 snapshot 中当前 Space、Tab、pane 的实际归属；不按名称、目录或相似标题自动匹配，不自动改绑到另一 machine。
- 地址、machine 或 SSH 连接定义发生变化时隔离原缓存、凭据关联和晚到响应；仅改显示名称保留有效状态。未配置、未认证、不兼容、目标不匹配分别给出可操作状态，终端仍可独立使用。
- 当前公开健康检查确认部署 web-ui 为 0.4.5、revision `5d18c535caf042bef69e569aa1f0299072760fde`，herdr 0.9.1 / protocol 22，要求 token 认证。尚未读取任何真实聊天记录，认证后的接口与 machine 绑定待 App 内验证。不能仅按版本号认定协议一致。

## 数据、发送与附件

聊天读取使用服务的结构化 conversation API，含分页、ETag、history_id 和历史替换检测。实现一个独立的服务适配模块；不得把 HTML 整页或 ANSI 输出冒充结构化聊天。复用参考渲染组件是实现者选择，但不依赖远端页面的脆弱 DOM 注入隐藏工具栏。凭据不交给渲染层。

文字发送继续走当前已认证 SSH 的 `agent.prompt`，使用当前已有 Agent 身份，不为发送另外打开 web-ui PTY。服务的 HTTP `/pane/input` 只输入字符，不能当作提交消息接口。提交中禁重复点击；确认成功才清空对应草稿；失败或结果不确定保留草稿并告知，不自动重发。首版不新增 web-ui 排队/延迟发送能力。

附件入口允许从系统文件/照片选择器选择文件，复用服务的上传接口，将成功返回的远端路径作为消息引用。采用服务现有 8 MiB 单文件限制；上传失败保留文字草稿，上传完成后才允许发送含该附件的消息。服务只读凭据或不支持上传时明确说明。历史图片和长工具输出按实际服务引用按需读取；不能凭空造出文件或跨 machine 读取。发送附件引用仍通过当前 SSH Agent，上传前须已验证同一目标绑定。

模型与推理强度只展示返回的实际 metadata；没有数据时不显示猜测值。服务不支持的内容保留可读降级说明，未知未来 part 类型不能导致整页空白。

## 模式、恢复与完成未读

实现者选择：Agent 首次默认聊天，普通终端默认终端；按开发机、Space、Tab、pane 保存本次运行的模式选择，后续返回优先使用有效记忆。已有冷启动持久上下文任务不在此扩大承诺。

模式切换不重连 SSH，不抢终端控制权；保留终端渲染器和未发送草稿、聊天滚动及历史。仅可见且前台的聊天按参考节奏更新（通常每 2 秒，状态变化时提前刷新），后台停轮询；返回前台保留已有内容，验证并刷新。HTTP 错误不拆除 SSH；SSH 错误不抹掉已经显示的聊天。连接验证未完成时输入和已读确认立即暂停，慢恢复以紧凑状态提示，不先显示空白/No Agent Selected，不显示假的“仍在线”。

聊天服务地址、web machine、原生开发机连接代次、pane 和 history_id 组成缓存/响应校验边界；旧目标晚到响应不得发布到新目标，历史换代不得拼接旧页。

已确认的已读扩展：终端沿用现有真实画面就绪规则；聊天模式成功在前台呈现当前身份、当前历史的最新完成回复也算查看本客户端结果。仅选中、缓存画面、HTTP 失败、空历史、普通 scrollback 降级、恢复提示或没有证明包含最新完成结果的响应不清蓝点；完成转变后须重新验证内容。Mac 与 iPhone 仍各自记录，不互相清除。此项已随整体规格确认，实施时更新 ADR。

## 验收与任务拆分

以下拆分接在已有 #23 和 #25 之后，按已确认的本扩展规格补充任务，不把旧移动截图算作新布局完成：

- **聊天服务绑定/认证**：地址保存、Keychain 凭据、machine 选择与身份核对，401/403/不兼容及晚到响应隔离。
- **conversation 读取/呈现**：真实协议、分页、ETag、换历史、Markdown/折叠/复制/图片/未知类型及前后台恢复；组件与输入层隔离。
- **聊天输入/附件**：已有 Agent SSH 提交、明确提交结果、草稿隔离及失败保留、文件选择/上传与目标核对。
- **参考界面整合**：原生顶部、默认收起侧栏、Tab 下拉、两种模式、更多菜单、暖色主题与保留底部栏。
- **最终验收**：同一受控数据对参考界面、iPhone 与保留布局的 Mac 验收；真机登录服务、目标绑定、真实聊天更新与发送、模式切换、锁屏恢复。

测试重点为模块公开行为及实际页面，不为配色常量写镜像测试。检查重复名称/相同 pane 字符串跨 machine、快速切换晚返回、未认证不清已读、提交失败不丢草稿/不自动重复提交、换历史分页与图片归属。

在 iPhone 13 / iOS 18.7.3 验证浅色/深色、中文/英文、长标题、文字放大、至少 44 点操作区、键盘遮挡、Tab 滚动、附件与链接、模式切换及锁屏恢复。常规尺寸按参考截图严格比较；文字放大允许必要换行。记录来源与真实服务/受控夹具边界，不用受控传输替代真实服务验收，不承诺 iOS 后台永久运行。
