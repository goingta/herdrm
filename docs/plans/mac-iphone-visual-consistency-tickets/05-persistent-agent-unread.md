# V05 — 统一两端完成未读规则与本地保存

状态：拆分草案，尚未发布到 GitHub。发布后使用 ready-for-agent，且必须核对阻塞项。

## What to build

Agent 完成后，未查看结果的客户端显示蓝点；用户成功看到对应终端内容后，该客户端清除标记，重启不会丢失此前未读提醒。

## Acceptance criteria

- [ ] Mac 与 iPhone 使用同一判断规则，分别保存自己的未读状态；一端查看不清除另一端标记，不扩展远端协议。
- [ ] 首次快照和新出现的历史完成 Agent 不产生一批提醒；已知 Agent 的非完成→完成转变在当前终端不可见时标为未读。
- [ ] 前台成功显示当前 Agent 的终端内容才算查看；选中 ID、缓存占位、上一个连接画面、连接恢复页、预览页及后台选中不清除标记。
- [ ] 正在前台查看可用终端时完成不产生蓝点；已读后状态详情仍可读取已完成。
- [ ] 按开发机与 Agent 身份保存并恢复标记；切换、同名 Agent 和重启不串状态；权威状态确认新任务或删除后清除旧标记，暂时缺数据不视为删除。
- [ ] 明确改进 Mac 现有切离后清除和内存保存方式；未观察到的断线期间完成不保证补发提醒。

## Verification

在公共状态接口覆盖完成转变、真实终端就绪、选中但不可见、重启、同名目标隔离和权威删除；结合两客户端的实际终端观察确认互不清除，保留现有 Agent 状态回归。

## Blocked by

None — can start immediately. 现有两端已具备 Agent 状态和原生终端，本任务补齐所需显示就绪信号与本地状态；与主题或上下文存储代码重叠不自动构成依赖。
