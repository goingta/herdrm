## What to build

用户强制结束 App 后重新打开，回到保存的开发机和 Agent，找回草稿及待核对状态并重新附着当前终端。

## Acceptance criteria

- [ ] 没有实时快照时显示上次 Agent 的恢复状态；真正无选择才显示选择提示。
- [ ] 重建连接后核对目标，恢复草稿及待核对标记，不自动提交；远端目标消失时仍能取回草稿。
- [ ] 连接失败保留选择和草稿并允许重试；旧启动任务不能覆盖随后切换的目标。
- [ ] 获取远端当前终端画面，不承诺恢复进程终止前全部历史滚屏。

## Verification

保存未发送和未确认发送状态后分别强制结束，重启核对状态，并覆盖远端 pane 已删除和服务器不可达。
