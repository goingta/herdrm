# 17 — 可复制的连接与恢复诊断

状态：已批准并发布，标签 ready-for-agent；实施尚未开始。GitHub：[[iPhone] 17 — 可复制的连接与恢复诊断](https://github.com/goingta/herdrm/issues/17)。

## What to build

用户在连接或预览失败后查看时间、阶段、错误和重连耗时，复制脱敏诊断以描述问题。

## Acceptance criteria

- [ ] 同时区分控制连接、终端和预览状态；一个通道可用不掩盖其他通道失败。
- [ ] 提供可执行的普通提示，展开后显示阶段、事件时间、错误类别和恢复耗时，并可复制。
- [ ] 诊断不包含私钥、密码、prompt 正文或完整敏感 URL 查询参数；日志保存和事件缓冲有界。
- [ ] 恢复诊断失败不影响实际 Agent 操作或预览；不新增远端自动修改权限或服务管理动作。

## Verification

使用带明显测试凭据、prompt 与 URL 参数的错误场景，核对复制内容脱敏、阶段归属和耗时记录。
