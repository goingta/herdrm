# 04 — 服务器指纹确认与变化处理

状态：已批准并发布，标签 ready-for-agent；实施尚未开始。GitHub：[[iPhone] 04 — 服务器指纹确认与变化处理](https://github.com/goingta/herdrm/issues/4)。

## What to build

首次连接由用户核对服务器指纹后信任；指纹变化时阻止认证，用户核对后才能明确更新信任。

## Acceptance criteria

- [ ] 首次连接展示主机、端口、算法与指纹，明确确认后才提交身份认证。
- [ ] 已信任端点正常复用记录；变化时展示旧、新指纹，取消或关闭页面不会继续认证。
- [ ] 重新信任必须由用户明确操作；自动重试不能跳过检查。
- [ ] 多个配置引用同一端点时，编辑或删除一条配置不会意外解除其他配置仍需要的信任记录。

## Verification

使用真实 sshd 切换主机密钥，观察首次确认、变化阻断、拒绝和重新信任；核对认证是否实际发生。
