## 已确认测试边界

用户整体批准的规格包括模块公开配置/服务操作和实际页面控件。HTTP、SSH、Keychain、时钟等系统边界可替代；不测试内部私有实现或颜色常量。以已知独立协议夹具覆盖认证错误、身份归属、分页/304/换历史、旧响应、失败草稿与不重复发送、上传限制/失败、模式/底部导航与前后台恢复。新功能按 red→green 一次一个行为切片。

真实渲染与当前完成内容的证明分别检查，HTTP 返回或选中不算查看。未能证明当前最新完成结果时保持未读，不能用快照到达替代画面呈现。

## 外部依赖与验收

已有服务公开 health 已验证，需要用户在 App 登录后选择对应 machine；不读取 Safari 凭据、不导出完整 App 偏好、不改变远端服务。App 内登录前实施可使用受控协议夹具完成。真实业务 Agent 的验收发送由用户选定目标；旧 POC 回复与受控 PTY不证明新增真实聊天链路。

真机和模拟器由各分支分配专用设备/夹具，正式 App 安装保留原配置和密钥。Mac 保留原布局和配色；iPhone 仅工作区采用参考项目暖黑/琥珀色视觉，底部三入口行为保留。
