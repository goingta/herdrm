# 已读状态归客户端所有

2026-10-10 已确认。herdr 服务端提供 Agent 运行状态，但没有客户端已读状态；跨设备同步会引入服务端扩展及不同客户端的查看冲突。本轮选择让 Mac 与 iPhone 分别持有并保存完成未读标记，共用判断规则和视觉表现，以实现一致体验并保持现有远端协议兼容。

清除未读表示当前客户端成功向前台用户显示了对应终端内容，不改变 Agent 的运行状态，也不清除另一客户端的标记。未来若增加跨客户端同步，须重新定义状态归属与冲突规则，不能把本地标记直接当作远端任务状态。


2026-10-11 扩展规格已确认：iPhone 的真实聊天模式也可确认查看当前完成结果。确认必须来自前台可见的渲染文档，并匹配当前开发机连接代次、Space、Tab、pane、history_id 和完成代次；HTTP 请求成功、缓存、选中页面和 scrollback 降级均不是证明。完成状态转变后，应验证最新回复相较完成前已更新；无法证明时保留蓝点。

聊天确认是一次性清除当前结果，不注册持续“已显示”状态。下一次完成须重新验证渲染的回复；隐藏的 SSH 终端不得替聊天模式确认。Mac 的终端确认与客户端独立状态归属保持原约定。
